## My process
- I started with the desktop view. A lot of people always say to start with mobile instead but I don't see how that works. Desktop looks so complicated and I'd rather deal with that first.
- Added the share panel and started working on the javascript.
- I think this is the only javascript project I've had fun with. It was smooth unlike the form validation project.
- I had issues working on the mobile aspect trying to toggle the share panel.
- I had to take a lot of rest. I can't remember precisely when I started this project which is why I want to work on my time management skills. It,s not up to a month though, lol.
